# qd-136 室内冲浪馆浪道辅助设备浪高档位适配绑定统计系统

## 项目简介

室内冲浪馆浪道辅助设备、浪高档位与绑定统计系统。项目包含 Vue/Vite 前端、Spring Boot 后端、MySQL 与 Redis，已按依赖层缓存和固定端口交付链路规范整理。

- 127.0.0.1 地址: [http://127.0.0.1:8156](http://127.0.0.1:8156)

## 角色与档位授权（辅助设备绑定页）

绑定页（`/binding`，辅助设备与浪高档位绑定）按角色收窄可见与可操作范围，**越权拦截以后端为准**（请求头 `X-Role` 标识当前角色）：

| 角色 | X-Role | 可见范围 | 可操作范围 |
| --- | --- | --- | --- |
| 馆长 | `DIRECTOR` | 全部浪高档位、全部设备 | 全部绑定 / 调整 |
| 浪道教练 | `COACH` | 仅授权档位上的防滑扶手、缓冲挡垫 | 仅能查看并调整授权档位上的防滑扶手、缓冲挡垫 |

- 教练默认授权档位为低浪 `LOW`、中浪 `MEDIUM`（高浪 `HIGH` 未授权），可在
  `backend/src/main/resources/application.yml` 的 `surf.security.coach-authorized-wave-levels` 配置。
- 教练对**未授权档位**发起绑定或调整（含把未授权档位上的设备调整走）时，后端返回
  `403 没有权限：……`，前端弹错提示，数据不会被改动。
- 绑定状态、可选设备、调整记录均由后端按角色过滤；刷新页面后列表仍只显示该角色被授权的设备
  （角色保存在浏览器 localStorage）。
- 顶部可切换“馆长 / 浪道教练”视角用于演示与验收。

## 缓冲挡垫适浪厚度校验（高浪档位）

缓冲挡垫改绑浪高档位时，必须达到目标档位的缓冲厚度下限，**拦截以后端为准**：

- 浪高档位通过 `wave_level.min_buffer_thickness` 配置厚度下限（数据初始化时高浪 `HIGH` 为 `10.0cm`，低浪/中浪不限制；旧库启动时自动回填）。
- 初始绑定 `/api/binding/bind` 与档位调整 `/api/binding/adjust` 在任何数据落库前，都会校验“缓冲挡垫”的 `buffer_thickness`；厚度不足或未登记时返回 `400 厚度不足：……`，前端弹窗提示。
- 调整场景下校验先于旧绑定失效执行：厚度不足时设备不会绑上高浪，原档位绑定也保持不变。
- 绑定不入库，因此刷新后“绑定状态”、按档位查询（高浪名单）与统计接口中都不会出现这块厚度不足的挡垫。
- 前端在设备下拉中显示挡垫厚度，选择设备与档位后即时红字提示；前端预校验仅为体验优化，绕过前端直接调接口同样会被后端拦截。

## 开浪前点检盘点（馆长）

馆长每晚开浪前对入浪防滑扶手、缓冲挡垫做点检盘点（页面 `/inspection`，菜单“开浪前点检”）：

- 防滑扶手记**握把打滑次数（次）**，缓冲挡垫记**挡垫移位（厘米）**；非本类型的指标强制置 0。
- 页上固定展示**今晚打滑合计**与**今晚移位合计**，由后端按当晚记录实时汇总；台账里直接改任意一条数字（或复点、撤回），两个合计立即重算跟上。
- **同一台设备同晚只保留一条记录**（唯一约束 `inspection_date + equipment_id`）：同设备再点一遍走覆盖更新而不是新增，合计只算一次；接口返回 `reInspected` 标识并提示。
- **现场对账**：录入现场另记的打滑/移位小计，后端与页上合计逐项比对，显示“账实相符 / 账实不符”及差异（页上 − 现场）。
- 仅馆长可访问；教练访问后端一律 `403 没有权限：开浪前点检盘点仅馆长可操作`，前端也收窄为无权限提示。接口前缀 `/api/inspection`。

## 设备领用与归还（设备管理页）

防滑扶手等设备可在设备管理页（`/equipment`）登记领用/归还，在借状态以**领用台账（`equipment_loan`）为唯一依据**，设备名单上的“在借/空闲”由台账回填，从根上避免“已借给教练、名单仍显示空闲、第二人又登记借走”的两本账对不上：

- **领用**：填写当班教练姓名后登记。设备存在未归还记录（`returned_at` 为空）时后端拒绝再次领用，返回 `400 该设备已借给 X X，尚未归还，不能重复领用`，名单上该设备标为“在借 · 教练姓名”并显示领用时间。
- **归还**：点“归还”确认后写入归还时间，设备回到“空闲”，之后才能再次被领用。
- **关页再开不丢、不残留**：在借状态随台账落库，刷新页面后仍在借的仍标“在借”；已还清的不再标记。设备停用时若仍在借，领用记录同事务结清。
- 教练只能领用/归还防滑扶手、缓冲挡垫两类辅助设备，越权 `403`。接口前缀 `/api/equipment-loan`（`/borrow`、`/return/{equipmentId}`、`/active`、`/history/{equipmentId}`）。

## 编译与启动

```bash
cd backend
mvn compile -q

cd ../frontend
npm ci
npm run build

cd ..
docker compose up -d --build
```

Docker Compose 端口均绑定到 `127.0.0.1`，镜像基础地址通过 `.env` 中的 `DOCKER_REGISTRY` 统一控制。
